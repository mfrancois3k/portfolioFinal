UI

01 / The UI

TRUST IS THE PRODUCT
Editorial hero, human first

A bold blue panel — “Empowering the Haitian spirit.” — sits over real Haitian landscape photography. The mission leads; the ask (FUND A PROJECT) follows.

Funding progress in the open

Each active project — a tourism corridor, a water network, a rice cooperative — shows its location and live funding progress. Donors see exactly where money goes.

Four pillars as architecture

Capital, Capacity, Connectivity, Accountability structure the whole site — every section answers to one of them.

Transparency as navigation

Impact maps, transparency reports, financial disclosures and governance docs are first-class footer destinations, not buried PDFs.

A full product surface

Language selector, site search, newsletter capture, and a donor portal login — the chrome of a serious platform, not a brochure.

02 / The Engineering

NEXT.JS IN PRODUCTION
NEXT.JS (APP ROUTER) · REACT · DONOR PORTAL · TRANSPARENCY REPORTING
Next.js App Router

Built on the modern Next.js app directory — server components, chunked builds, and route-level code splitting out of the box.

Accessible from the first element

The document opens with a skip link — keyboard and screen-reader users bypass the chrome and land on content.

Donor portal + gated flows

Authenticated portal entry point for contributors, separated from the public marketing surface.

Content built to scale

Projects, contributors, and impact reporting are structured sections — new projects slot into the system rather than new pages being hand-built.

Performance-minded delivery

Optimized image delivery over full-bleed photography keeps a visually heavy site fast.
