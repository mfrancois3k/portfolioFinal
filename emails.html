GRUBHUB

01 / Grubhub — The UI

TRANSACTIONAL, ON-BRAND
Reads in one glance

Order status, pickup window, and a map — the three things a hungry customer actually wants — stack in the first screen.

One dominant action

A single bold “Get Directions” button; secondary actions stay quiet links.

On-brand without images-only

The orange header and type hierarchy hold the brand even with images off — no image-only design that collapses in dark inboxes.

HTML TABLES

Table layout that holds

Nested HTML tables with explicit widths — the only layout Outlook's Word engine respects.

Bulletproof CTA

The button is padded table cells and background color, not an image — it renders (and clicks) everywhere.

Litmus across clients

Tested in Litmus against Outlook, Gmail, and Apple Mail before calling it done.

BRUMS

03 / Brums Milano — The UI

EDITORIAL FASHION LAYOUT
Magazine energy in an inbox

Overlapping color blocks and oversized “KEY” type bring a lookbook feel that most email layouts flatten out.

Category nav up top

Baby Girl / Newborn / Girl / Fall Winter — shoppers jump straight to their section.

Image-led, safely

The design leans on photography but keeps structure and nav in HTML, so a blocked image never kills the email.

04 / Brums Milano — The Engineering

LAYERED, RESPONSIVE
HTML/CSS · HYBRID RESPONSIVE · LITMUS
HYBRID RESPONSIVE
LAYERED BLOCKS
Layered look, table bones

The overlapping blocks are aligned table structures and offsets — no CSS positioning that email clients strip.

Responsive by fluid hybrid

Fluid widths with max-width caps adapt from desktop preview panes to phones without media-query-only tricks.

Web-safe fallback stack

Brand type falls back to a matched web-safe stack, so the hierarchy survives every client.

LINKEDIN

05 / LinkedIn Alert — The UI

A SCANNABLE DIGEST
Row rhythm

Every job is the same tight row — title, company, location, status — so four jobs scan in four seconds.

Status signals

“Actively recruiting” icons give a reason to click now, not later.

Zero decoration

It's a utility email; the design's job is to disappear behind the listings.

GRID

06 / LinkedIn Alert — The Engineering

BUILT FOR REPETITION
HTML TABLES · TEMPLATE ROWS · LITMUS
STRICT TABLE GRID
TEMPLATE-READY ROWS
Strict table grid

Thumbnail, copy, and status columns lock to a fixed grid, so rows never drift as content length changes.

Template-ready structure

Each job row is a self-contained block — the layout is built to be generated per-user with any number of rows.

Alt text everywhere

Logos ship with alt text and dimensions, so blocked images leave a readable email, not a puzzle.
