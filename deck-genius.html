React front end

Component-driven builder UI, prototyped and iterated quickly.

Supabase backend

PostgreSQL schema for cards, decks, and users designed on Supabase — auth and storage come with the platform.

151-agent prompt system

Deck analysis is driven by a structured multi-agent prompt system — specialized prompts for archetypes, ratios, and matchup reasoning.

Billing designed, not bolted on

Payment infrastructure was planned into the schema from the start for a future paid tier.

Honest status
